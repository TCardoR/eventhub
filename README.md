# EventHub

EventHub es una plataforma backend para la administración de empresas,
contactos, eventos, reservas, pagos y notificaciones.

El proyecto se desarrolla como una ruta de aprendizaje práctica enfocada en
Java, Spring Boot, arquitectura limpia, pruebas automatizadas, seguridad,
contenedores, nube y prácticas DevOps.

## Estado

Proyecto en etapa de planificación y preparación técnica.

## Objetivos técnicos

- Aplicar programación orientada a objetos con Java.
- Construir una API REST con Spring Boot.
- Persistir información en PostgreSQL y DynamoDB.
- Implementar autenticación y autorización con JWT.
- Aplicar Clean Architecture y arquitectura hexagonal.
- Crear pruebas unitarias y de integración.
- Containerizar la aplicación con Docker.
- Orquestar servicios con Kubernetes.
- Implementar integración y despliegue continuos.
- Desplegar componentes en AWS.

## Estructura inicial

- `backend`: código fuente del backend.
- `docs`: documentación funcional y técnica.
- `diagrams`: diagramas del sistema.
- `infrastructure`: contenedores e infraestructura como código.
- `scripts`: utilidades para desarrollo y mantenimiento.
